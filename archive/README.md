# Research archive

These historical experiments are retained as evidence, not as supported submission commands.
Their original paths and complete runnable source are preserved by tag
`research-archive-2026-09-30` (commit `667ca22`). To reproduce an old run, use
a separate checkout of that tag; archived scripts may depend on original paths.
The release includes the full source archive and checksums.

The current submission does not use Q8/OpenVINO acceleration. C4 stopped
incomplete at the user's request; both C3-E2 attempts were void.
